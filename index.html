Kirim pesan
melalui WhatsApp.

Tautkan akun WhatsApp milikmu melalui perangkat tertaut, lalu kirim pesan dari panel web. Server harus tetap berjalan agar koneksi aktif.

1. Pengaturan panel

Kunci disimpan di localStorage browser perangkat ini. Jangan bagikan kunci panel.

Status belum diperiksa.

2. Tautkan WhatsApp

Masukkan nomor akun sendiri dengan kode negara, tanpa tanda +. Contoh Indonesia: 62812xxxxxxx.

Di WhatsApp: Setelan/Settings → Perangkat tertaut → Tautkan perangkat → Tautkan dengan nomor telepon, lalu masukkan kode.

3. Kirim pesan

Kirim hanya ke penerima yang mengharapkan atau menyetujui pesanmu. Hindari spam.

Kontrol koneksi

Web Messenger · Data sesi WhatsApp tersimpan di server. Jangan bagikan folder auth_info atau kunci panel.
